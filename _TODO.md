# Что осталось сделать

Записано 27.10.2026, чтобы не забыть к следующему разу.

## 1. Установщик пишет в Program Files без прав

**Проблема.** При установке 2.7.0d появляется:

```
Не возможно создать папку "C:\Program Files\TGPlayer".
Ошибка 5: Отказано в доступе.
```

**Причина.** В `installer/tgplayer.iss` стоит `PrivilegesRequired=lowest`
(установка без прав администратора). При этом `DefaultDirName={autopf}`
при такой настройке должен раскрываться в `%LocalAppData%\Programs`, а
не в `C:\Program Files`. Значит, `{autopf}` ведёт себя иначе, чем
ожидалось, — и установщик лезет туда, куда писать не имеет права.

Кроме этого, папку теперь можно выбрать (добавили `DisableDirPage=no`),
и кто-то мог указать `Program Files` вручную.

**Что проверить/сделать завтра.**

- Понять, куда реально раскрывается `{autopf}` на этой системе.
  Скорее всего, `ArchitecturesInstallIn64BitMode=x64compatible` вместе с
  `PrivilegesRequired=lowest` даёт неожиданный результат.
- Варианты:
  - вернуть `DisableDirPage=yes` и жёстко ставить в `%LocalAppData%\Programs`;
  - либо сменить на `PrivilegesRequired=admin` (потребует UAC, зато
    `Program Files` станет доступен);
  - либо оставить выбор папки, но в `InitializeWizard` подставлять путь,
    в который писать можно.
- **Проверить на чистой установке**, а не только через `/DIR=`.

Вчерашняя ошибка была другая — «отказано в доступе» для папки `Temp`,
она была разовой и сейчас не повторяется. Это разные вещи.

## 2. SmartScreen при запуске

Плеер не подписан, Windows предупреждает. Полностью убрать бесплатно
нельзя — нужен сертификат подписи кода.

Варианты (обсуждали):

- **EV-сертификат** (~$300-600/год) — репутация сразу, предупреждения нет.
- **OV-сертификат** (~$200-400/год) — репутация набирается месяцами.
- **Самодельный сертификат** (бесплатно) — работает, только если каждый
  пользователь вручную добавит его в доверенные. Для узкого круга годится.
- **Ничего не делать** — «Подробнее» → «Выполнить всё равно».

Решение отложено: надо понять, как раздаётся плеер — публично или
узкому кругу.
