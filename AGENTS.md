# Инструкции для агента: проект Tegr

Файл для новой сессии. Прочитай его целиком перед первой правкой.

## 1. Что это за проект

Tegr — видеоплеер для Telegram на Python 3.11 + PyQt6 (+ libmpv через
python-mpv), сборка PyInstaller.

- Рабочий каталог: `H:\deepseek projects\tegr new`
- Точка входа сборки: `player_tegr.py` → `TegrMainWindow` из
  `tegr/windows/tegr_window.py` (наследует `MainWindow` из
  `tegr/windows/windows.py`)
- Версия задаётся ТОЛЬКО в `tegr/core/version.py` (`MAJOR/MINOR/PATCH`).
  `version_info.txt` и `installer/Tegr.iss` держать в синхроне.
- Тестовое видео: `C:/Users/yolorik/Videos/2026-11-01 21-15-07.mp4`

## 2. Как я должен работать (главное)

1. **Искать причину, а не симптом.** Заглушки, «костыли» и «попробуем так»
   не принимаются. Сначала замер/воспроизведение, потом правка.
2. **Проверять на настоящем рендере.** Многие беды видны только на экране:

   теме не видна как вспышка — она сливается с белым.
4. **Каждая правка — прогон.** 73 теста + мой временный прогон. Временные
   файлы после проверки удалять; бэкапы делать в `_backups/`.
5. **Не менять то, чем довольны.** Есть список «не трогать» (раздел 6).
6. **Не собирать .exe/установщик без явной просьбы.**

## 3. Сборка и запуск

```powershell
# Проверочная сборка (для пользователя, данные сохраняются)
.\_build.ps1 -DistDir 'test_dist' -BuildDir 'test_build'
Copy-Item 'test_dist\Tegr\Tegr.exe' 'Tegr_test\Tegr.exe' -Force
Get-ChildItem 'test_dist\Tegr' -Directory | ForEach-Object { Copy-Item $_.FullName 'Tegr_test' -Recurse -Force }
Remove-Item 'test_dist','test_build' -Recurse -Force

# Релизная сборка
.\_build.ps1 -DistDir 'dist' -BuildDir 'build'
.\_build_inst.ps1          # → releases\<версия>\Tegr_Setup.exe + SHA256.txt
```

Перед сборкой закрыть запущенный `Tegr` (иначе скрипт откажется).
ISCC (Inno Setup 6) лежит в `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`.

Тесты: `QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests`

## 4. Тема и цвета — где что лежит

- `tegr/core/theme.py` — темы (`paper`, `sand`, `fog`, `graphite`), `theme()`,
  `scale_px()`, `set_theme_key()`.
- `tegr/windows/tegr_window.py::build_tegr_style()` — QSS всего окна.
- **Подложки строк — ПЛОТНЫЕ цвета, не `rgba()`.** Полупрозрачная заливка
  кладётся поверх уже нарисованного и копится: строка светлеет от наведения
  к наведению и обратно не темнеет (было: `#101214 → #464747` за 5 касаний).
  Считать смешанный цвет один раз (`_mix` в `build_tegr_style`).
- **Фон окна только через QSS.** `QPalette` окна НЕ трогать: она запоминает
  цвет при создании и перебивает потом любую тему — окно навсегда остаётся
  темой запуска.
- Жёсткие `#000000` у `#playerroot`, `#playervideo`, `#playervideobox`
  убраны нарочно; фон берётся из стиля темы.

## 5. Показ окна из трея и релизы

Показ из трея (`_show_from_tray` в `tegr/windows/windows.py`):

- Windows выводит окно на экран **до** отрисовки Qt → первый кадр пустой.
  На тёмной теме он почти белый — это и есть «вспышка».
- Рабочий порядок: `_prime_for_show()` (отрисовать содержимое, пока скрыто)
  → `show()` → `repaint()` → `QTimer.singleShot(0, _settle_after_tray)`.
- **`WA_TranslucentBackground` НЕ включать.** Проверено: снятый после показа
  слой оставляет окно в слоёном режиме — подложки копятся от касаний, фон
  схлопывается в чёрный. Это регресс, который уже дважды ловили.
- Цвет класса окна (`SetClassLongPtrW`) задаётся при создании и обновляется
  в `_apply_theme()` — иначе после смены темы пустой кадр остаётся цветом
  прежней темы.

Релиз:

1. `tegr/core/version.py` (`MONOR/PATCH`) + `version_info.txt` + `Tegr.iss`
2. тесты, `_build.ps1`, `_build_inst.ps1`
3. проверить установщик на этой машине (тихая установка → запуск → удалить)
4. `git commit`, `git tag -a <версия>`
5. `git push origin main && git push origin <тег>`
6. **`gh release create <тег> releases/<версия>/Tegr_Setup.exe releases/<версия>/SHA256.txt --title "Tegr <версия>" --notes-file ...`**
7. проверить через `api.github.com/repos/yolorik/tegr/releases` — свежий
   выпуск первым. Плеер ищет обновление именно там (`tegr/core/updates.py`).

**Не забывать шаг 6.** Один раз я выложил только тег — и выпуска не было.

## 6. Не трогать (пользователь доволен)

- Панель управления: вход/выход PiP, вход в фуллскрин, высота панели.
  В фуллскрине центрируется по кадру видео (ширина 760, низ = низ кадра − 36);
  в оконном — во всю ширину.
- Список канала: во всю высоту окна, слайд с растворением; при открытии
  кадр сужается, панель едет за кадром.
- **Переход в фуллскрин — БЕЗ анимации** (пользователь потребовал вернуть
  «как было»).
- Строки списка: ширина и шрифт.
- Повторный запуск ярлыка — разворачивает окно из трея без предупреждения.

## 7. Известная открытая проблема

Падение процесса `0xe24c4a02` при входах/выходах из фуллскрина. Воспроизводится
в минимальном окне, где только создан mpv (`vo=gpu/sdl/image`,
`hwdec=d3d11va/d3d11va-copy`): 3 падения из 6 прогонов, иногда в
`mpv.py:_event_generator`, иногда в `tegr/core/log.py` (`tee_print`).
Это libmpv и способ вызова на этой машине, НЕ логика перехода в фуллскрин.
Не исправлено. QtMultimedia как замена вывода (`image://mpv`) пробовали —
чёрный экран при живом звуке, откатали.
